## Page recipes

Use as starting points, then vary. Don't repeat the same section shape twice in a row.

- **Landing**: header (logo, `NavigationMenu`, one CTA) → hero (left-aligned or split with visual; headline ≤ 10 words, one sentence of support, primary + secondary action) → proof (logos or one metric row) → features (bento or alternating split, not 3 identical cards) → detail/how it works → testimonial or case → pricing (`Card` tiers, highlight one) → FAQ (`Accordion`) → final CTA → footer.
- **Dashboard**: `Sidebar` shell → page header (title, date range, primary action) → KPI row (3–4 `Card` with value, delta `Badge`, sparkline) → main chart → table or `Item` list → `Empty` / `Skeleton` states for each.
- **Settings**: `Sidebar` or `Tabs` for sections → `FieldSet` per group with description column on desktop (`md:grid-cols-[1fr_2fr]`) → `Switch` for instant toggles, explicit save for forms → danger zone with `AlertDialog`.
- **Auth**: split layout on desktop (form + brand panel), single column on mobile; `Field` stack, `InputOTP` for codes, clear error copy.
- **Detail page**: `Breadcrumb` → title + status `Badge` + `ButtonGroup` actions → main content + side metadata column (`lg:grid-cols-[1fr_320px]`).
